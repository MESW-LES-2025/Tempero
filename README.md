# Tempero
https://mesw-les-2025.github.io/Tempero/

**Tempero** is a modern recipe-sharing and meal-planning web application designed to help users build better culinary habits, discover new dishes, and connect through food.

### Key Features
* **Discover & Share:** Explore, upload, and review community-submitted recipes.
* **Smart Search & Filters:** Quickly find recipes based on ingredients, dietary needs, or preferences.
* **Personalized Assessments:** Get tailored recommendations matching your taste and cooking skill level.
* **Organization:** Save favorites and build custom recipe lists for seamless meal planning.
* **Community & Profiles:** Share culinary ideas and interact with other home cooks.

Explore the project in depth on our [Wiki](https://github.com/MESW-LES-2025/Tempero/wiki).
